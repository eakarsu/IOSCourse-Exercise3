# Privacy disclosure

Multiples is a local-only arithmetic exercise. It has no account, network request, advertising, tracking, analytics, crash-reporting SDK, or remote database. The multiplier and current step are stored only in the app's UserDefaults container for interruption recovery. Reset or completion removes that state; uninstalling the app removes its container.

The checked-in privacy manifest declares no tracking, collected-data categories, or required-reason APIs. Reassess both this disclosure and the manifest before adding any SDK or network capability.
